# /api-doc

## 무엇을 하는가

작성된 API의 API 명세서를 지정한 양식의 HTML 로 만들어 브라우저로 제공하는 하네스.

## 왜 만들었는가

API 를 만들고 Jira 댓글로 작성하여 빠르게 공유하기 위함.

## 어떻게 쓰는가

말로 시켜도 불려오고(`"이 API 명세서 만들어줘"`), `/api-doc` 으로도 부른다.
산출물은 **작업 중인 프로젝트가 아니라 이 폴더의 `output/`** 에 쌓인다.
`.gitignore` 의 `docs/skills/*/output/*` 로 덮여 있어 커밋에는 섞이지 않는다.
