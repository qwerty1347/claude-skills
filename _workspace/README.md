# _workspace

스킬이 실행 중에 만드는 중간 산출물을 두는 곳.

## 규칙

파일 이름은 이렇게 짓는다.

```
{단계}_{주체}_{산출물}.{확장자}
```

예시:

```
01_draft_case-study.md
02_review_feedback.md
03_final_case-study.md
```

중간 파일을 지우지 않고 남기는 이유는, 결과가 이상할 때
**어느 단계에서 틀어졌는지** 되짚기 위해서다. 최종 결과물만 남기면
"왜 이렇게 나왔지" 에 답할 수 없다.

## git

이 폴더의 내용물은 기본적으로 `.gitignore` 처리된다.
남길 가치가 있는 산출물만 `git add -f` 로 강제 추가한다.
